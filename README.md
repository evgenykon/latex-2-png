# LaTeX → PNG

Одностраничный инструмент конвертации LaTeX-формул в PNG прямо в браузере. Никакого бэкенда: рендеринг делает [MathJax 3](https://www.mathjax.org/) (SVG), после чего картинка переносится в `<canvas>` и сохраняется как PNG.

Онлайн-версия: <https://evgenykon.github.io/latex-2-png/>

## Возможности

- Ввод формулы на LaTeX + кнопки быстрой вставки шаблонов (дробь, корень, сумма, интеграл, греческие буквы и т. д.)
- Выбор цвета текста и цвета фона, включая **полностью прозрачный фон** (PNG с альфа-каналом)
- Настройка размера шрифта (в пунктах)
- Размер картинки:
  - **Авто** — по фактическому размеру формулы
  - **Вписать в размер** — с сохранением пропорций и центрированием на холсте заданной ширины и высоты
- Живой предпросмотр и скачивание результата одной кнопкой
- Тёмная тема (Tailwind CSS)

Вторая страница (`plot.html`) — графики функций:

- Рендер графиков на [Plotly.js](https://plotly.com/javascript/) с нативным LaTeX в легенде (встроенный MathJax)
- Формула на LaTeX парсится в JS-функцию движком [@cortex-js/compute-engine](https://github.com/cortex-js/compute-engine) (`compile('\\sin(x)')` → `fn.run({x})`)
- Параметры-константы: `ax^{2}+bx+c` + поле «Параметры» со значениями `a=1, b=2, c=-3`; неизвестные переменные подсвечиваются ошибкой с подсказкой
- Настройка диапазонов x/y, числа точек
- Переключатель «Автомасштаб по Y»: выключен (по умолчанию) — фиксированный диапазон Y, и изменение параметров (например `a` в `a x^2 + b x + c`) видно сразу; включён — диапазон Y подстраивается под данные
- Настройка шрифта легенды (семейство, размер, цвет), цвета осей, сетки и графика, толщины линии
- Фон настраивается, включая **полностью прозрачный** (PNG с альфа-каналом)
- Разрывные функции (`\tan(x)`, `1/x`) разбиваются на сегменты
- Живой предпросмотр и скачивание PNG через `Plotly.toImage`

Третья страница (`draw.html`) — рисовалка:

- Рисование мышью, стилусом или пальцем (Pointer Events)
- Инструменты: **перо** (сплошная линия), **маркер** (полупрозрачная), **кисть** (мягкие края), **ластик** (стирает в прозрачность)
- Выбор размера кисти (слайдер), цвета (палитра + выбор цвета) и цвета фона, включая **полностью прозрачный** (PNG с альфа-каналом)
- Настройка размера холста, отмена последних действий (undo) и очистка
- Сохранение в PNG с масштабированием ×1–×4 через `canvas.toDataURL`

Четвёртая страница (`pdf.html`) — просмотрщик PDF:

- Загрузка файла (кнопкой или drag & drop) и рендер страниц через [PDF.js](https://mozilla.github.io/pdf.js/)
- Режимы просмотра: одна страница, разворот (2 рядом) и книга (обложка отдельно)
- Анимация смены страниц: перелистывание (3D-поворот страницы), сдвиг, плавно, приближение (или без анимации)
- Настройка цвета фона области просмотра
- Оглавление (TOC) из закладок PDF: боковая панель с вложенными разделами, переходом по клику, **переименованием и удалением** пунктов (кнопка «Сбросить» возвращает исходное)
- Масштаб (по ширине, по высоте или 50–300 %), навигация стрелками/PageUp/PageDown/Home/End
- **Сохранение и открытие проекта**: сам PDF, отредактированное оглавление, фон и настройки вида в одном JSON-файле (`*.pdfproj.json`)

## Структура

```
index.html                  — LaTeX → PNG (формулы)
plot.html                   — графики функций → PNG
draw.html                   — рисовалка → PNG
pdf.html                    — просмотрщик PDF
.github/workflows/pages.yml — деплой на GitHub Pages
```
