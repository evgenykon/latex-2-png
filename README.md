# LaTeX → PNG

Одностраничный инструмент конвертации LaTeX-формул в PNG прямо в браузере. Никакого бэкенда: рендеринг делает [MathJax 3](https://www.mathjax.org/) (SVG), после чего картинка переносится в `<canvas>` и сохраняется как PNG.

Онлайн-версия: <https://evgenykon.github.io/latex-2-png/>

## Возможности

- Ввод формулы на LaTeX + кнопки быстрой вставки шаблонов (дробь, корень, сумма, интеграл, греческие буквы и т. д.)
- Выбор цвета текста и цвета фона, включая **полностью прозрачный фон** (PNG с альфа-каналом)
- Настройка размера шрифта (в пунктах)
- Размер картинки:
  - **Авто** — по фактическому размеру формулы
  - **Вписать в размер** — с сохранением пропорций и центрированием на холсте заданной ширины и высоты
- Живой предпросмотр и скачивание результата одной кнопкой
- Тёмная тема (Tailwind CSS)

## Как пользоваться

1. Откройте `index.html` в любом современном браузере (или на GitHub Pages).
2. Введите формулу в синтаксисе LaTeX без `$...$`, например `\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}`.
3. Настройте цвет текста, фон (или прозрачность), размер шрифта и размер картинки.
4. Нажмите **Сгенерировать PNG** и скачайте результат.

Нужен доступ в интернет: библиотеки подключаются с CDN.

## GitHub Pages

Для публикации на GitHub Pages используется GitHub Actions (см. `.github/workflows/pages.yml`).

Настройка один раз:

1. Загрузите репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите источник **GitHub Actions**.
4. Сделайте любой пуш в `main` (или запустите workflow вручную во вкладке **Actions → Deploy to GitHub Pages → Run workflow**).
5. Сайт будет доступен по адресу `https://<username>.github.io/latex-2-png/`.

Workflow собирает и публикует страницу автоматически при каждом пуше в `main`.
